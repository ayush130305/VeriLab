# VeriLab

Interactive lessons for digital design, from an FPGA point of view.

## Modules

- **Communication protocols** (`protocols/`): UART, SPI, QSPI, I2C, I3C, APB, AHB-Lite, AXI, CAN, I2S, Ethernet, USB 2.0 and common FPGA building blocks, with simulators and interview questions.

## Run it

Open `index.html` in a browser. There is no build step and no dependency.

## Note

Built with AI help as a learning tool. The simulators are simplified teaching models, not protocol-compliant implementations. Check exact values against the specification or datasheet.
